# Personal Portfolio Website

This repository contains the source code for my personal portfolio website. It showcases my skills, experience, projects, and certifications as a Backend Developer.

## 🚀 Technologies Used

- **HTML5** for structure
- **CSS3** for styling and animations
- **JavaScript** for interactivity and data loading

## 📂 Project Structure

- `index.html` — The main entry point of the website.
- `css/` — Contains stylesheets for the website design.
- `js/` — Contains logic for interactivity and rendering.
- `data/portfolio-data.js` — The central data file where all portfolio content (skills, projects, experience) is stored.

## 📝 How to Update Content

All the data for the portfolio is dynamically rendered from a single file.
To update your portfolio, simply edit the data inside `data/portfolio-data.js`. There is no need to modify the HTML directly.

## 🛠️ Local Development

1. Clone this repository:
   ```bash
   git clone git@github.com:rushitrabadiya/portfolio.git
   ```
2. Open `index.html` in your browser. No build steps or local servers are required!
